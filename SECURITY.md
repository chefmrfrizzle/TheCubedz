# Security Policy

## Scope

Please report vulnerabilities involving code execution, dependency compromise, secret exposure, data integrity, authentication, authorization, or reproducibility tampering privately to the maintainers once a contact method is published.

## Scientific integrity is also a security concern

The project should protect against:
- silently modified experiment artifacts;
- provenance deletion;
- model/prompt changes that alter historical interpretations without versioning;
- malicious candidate payloads;
- untrusted code execution;
- poisoned datasets;
- fabricated citations or evidence.

Candidate submissions should eventually execute in isolated, resource-limited environments.
