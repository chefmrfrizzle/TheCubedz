# Governance

## Principles

This is an open research project. Governance should optimize for reproducibility, scientific integrity, contributor safety, and long-term accessibility.

## Roles

- **Contributors** propose code, data, analyses, documentation, or reproductions.
- **Reviewers** review within their demonstrated domain expertise.
- **Maintainers** manage releases, repository health, and merge decisions.
- **Scientific reviewers** may be invited to review domain-specific claims.

No role grants authority to override reproducible evidence.

## Scientific changes

Changes that alter equations, validators, benchmark expectations, or candidate scientific status require explicit review notes and reproducibility evidence.

## Model and prompt changes

Models and prompts are versioned artifacts. A model update cannot silently rewrite historical scientific records. New models may generate new interpretations/proposals, but old results remain attached to the versions that produced them.

## Canonical record

The canonical record is the signed/versioned experiment ledger plus source artifacts — not an LLM's memory and not a dashboard summary.
