# Support

## Questions and orientation

Use GitHub Discussions once enabled for:

- beginner questions;
- architecture discussion;
- requests for explanation;
- coordination around benchmarks;
- contributor introductions.

## Bugs and bounded work

Use the repository issue forms for:

- software or website bugs;
- candidate proposals;
- scientific challenges;
- independent reproductions;
- documentation and accessibility work.

## Security and conduct

Do not use public issues for vulnerabilities with active exploit details or private conduct reports. Follow [SECURITY.md](SECURITY.md) and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## No individualized scientific certification

Maintainers cannot certify that an outside metric, device, investment claim, or transportation concept is physically valid merely through an informal support request. Submit a bounded candidate and evidence package through the normal research process.
