# Scientific claims policy

## Purpose

This project invites ambitious hypotheses while keeping public claims narrower than the evidence supporting them. A polished interface, large model, simulation, or popular contribution is not scientific validation.

## Claim classes

| Class | Meaning | Minimum evidence |
|---|---|---|
| `HYPOTHESIS` | A testable proposition or candidate definition | Assumptions, conventions, provenance, and falsification criteria |
| `COMPUTATION_SUPPORTED` | A versioned deterministic computation supports the statement within declared scope | Candidate hash, validator version, result artifact, methods, limitations |
| `REPRODUCED` | An independent implementation or environment recovered the result within tolerance | Reproduction record, environment, comparison, discrepancies |
| `EXPERT_REVIEWED` | Qualified reviewers accepted the methods and interpretation | Named review record and unresolved-objection log |
| `EXPERIMENT_SUPPORTED` | Physical observation supports a prediction | Protocol, measurements, uncertainty, independent replication |
| `FALSIFIED` | A decisive test failed under the declared scope | Failure artifact and downgrade rationale |
| `RETRACTED` | The project withdrew the claim | Permanent retraction record; history is never erased |

## Non-negotiable boundaries

1. Candidate validity, physical interpretation, stability, causality, energy requirements, and engineering realizability are separate assessments.
2. AI output enters working memory only. It cannot promote itself or modify canonical artifacts.
3. Votes, clicks, reputation, media attention, and repeated generated text cannot determine scientific status.
4. A validator may only claim the checks it implements.
5. Every public claim must identify what result would downgrade or falsify it.
6. Negative results, superseded results, and corrections remain discoverable.

## V0 language

Permitted:

- “The exact submitted Minkowski Cartesian baseline passed all implemented V0 checks.”
- “This verifies the baseline pipeline within its declared scope.”
- “The system is designed to map failures and unresolved regions.”

Prohibited:

- “The project proved wormholes are possible.”
- “The AI solved spacetime.”
- “The system found a route to Mars.”
- “A green score means a candidate is physically buildable.”
