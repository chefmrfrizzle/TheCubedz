# Public V0 launch acceptance criteria

The public release is acceptable only when every item below is true.

## Scientific integrity

- The first candidate is a known flat-spacetime baseline, not an exotic proposal.
- Every displayed status is derived from a committed machine-readable artifact.
- Passing the baseline is described as a software and reproducibility milestone.
- The public site states that no wormhole, warp mechanism, faster-than-light result, or Mars shortcut has been demonstrated.
- Unknown, unimplemented, and unreviewed questions remain visibly unknown.

## Reproducibility

- A clean clone can install dependencies, run the validator, and execute all tests.
- Reproducible mode produces the same scientific payload digest.
- Generated reports are derived from the same result object shown by the website.
- Candidate, validator, result, and source versions are visible.

## Product quality

- The site works without a database, account, secret, analytics service, or paid API.
- Mobile and desktop layouts are usable.
- Keyboard navigation, reduced-motion behavior, semantic headings, labels, and focus states are present.
- Broken links, placeholder URLs, build warnings, and browser console errors block launch.

## Open-source readiness

- License, contribution guidance, governance, code of conduct, and security reporting are present.
- CI runs scientific tests, website tests, and artifact freshness checks.
- The repository contains issue templates for research questions, reproductions, bugs, and falsification attempts.
- Claims, model promotions, and changes to canonical evidence require human review.

## Launch statement

The release may say:

> This is an open computational experiment for representing, checking, explaining, challenging, and eventually searching spacetime candidates. V0 verifies one exact flat-spacetime baseline. It does not demonstrate a transportation mechanism.
